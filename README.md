# YouthEscalateBench

Dynamic multi-turn youth safety moderation benchmark for causal cyberbullying and escalation detection. Includes a 12-stage pipeline, 10 ingested datasets (79k+ turns), 12 evaluated LLMs/baselines across 3 context conditions, automated infographics, and 100% test pass rate (74/74).

## Quick Start
```bash
pip install -e ".[dev]"
python main.py --all --extended-report
```

See **[README_extended.md](README_extended.md)** for full documentation, metrics, and architecture.
